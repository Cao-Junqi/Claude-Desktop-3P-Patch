## 🚀 核心特性

### 1. 智能路径检测
- ✅ 从运行中的 Claude 进程获取路径（WMIC）
- ✅ 检查标准安装位置 fallback
- ✅ 支持 90% 以上的安装场景

### 2. 自动进程管理
- ✅ 自动检测 Claude 是否在运行
- ✅ 自动 taskkill 关闭进程
- ✅ 无需用户手动操作

- ✅ 7 层二进制 patch（从 macOS 完整移植）

## 📦 分发建议

### 推荐方式：局域网分发
**优点**:
- 100+ 学员同时获取不会拥堵
- 千兆局域网速度快
- 节省公网带宽

**操作**:
```
1. 上传到内网文件服务器
   例: \\fileserver\software\claude-patch\

2. 告知学员下载地址

3. 学员下载后按 README_WINDOWS.txt 操作
```

### 备选方式：U盘分发
**场景**: 无局域网或网络不稳定

**操作**:
```
1. 复制到 U盘
2. 学员从 U盘复制到本地 (例: D:\Claude-Patch\)
3. 按文档操作
```
