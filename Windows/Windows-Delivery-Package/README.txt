========================================
Claude Desktop 3P Patch - Windows 版
========================================

【安装步骤】

1. 下载 Claude Desktop 官方安装包
   https://claude.ai/download

2. 双击安装包安装 Claude Desktop

3. 启动 Claude Desktop（保持运行）

4. 右键 install.bat，选择"以管理员身份运行"

5. 等待自动完成，启动 Claude 即可看到中文界面


【系统要求】

- Windows 10/11 (64位)
- 管理员权限
- Python 3.8+ (https://python.org/downloads/)


【功能说明】

✓ 第三方模型支持（OpenAI/Azure/自定义）
✓ 完整中文汉化（24000+ 翻译）
✓ 禁用自动更新


【常见问题】

Q: 提示"需要管理员权限"
A: 右键 install.bat，选择"以管理员身份运行"

Q: 提示"未找到 Claude Desktop"
A: 先启动 Claude Desktop，保持运行，再运行 install.bat

Q: 提示"需要 Python"
A: 下载安装 Python 3.8+，安装时勾选"Add Python to PATH"

Q: Patch 后界面仍为英文
A: 完全退出 Claude（任务管理器确认），然后重启
